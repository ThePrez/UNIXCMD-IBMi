The full license text is at the top of each source member.

## Sources

This documentation draws on the following sources:

- **The UNIXCMD source code and help text in this repository.** This
  includes the `UNIXPIPE_H` copybook, the `UNIXPIPER4`, `UNIXCMD` and
  `UNIXCMDOA` programs, the help panel groups for the CL commands, and the
  sample programs in `samples/rpg`. Statements about behavior throughout
  these pages come from the code unless a page says otherwise.
- Scott Klement, **_UNIXCMD: Integrating RPG with Open Source_**
  (presentation).
  <https://www.scottklement.com/presentations/UNIXCMD-%20Integrating%20RPG%20with%20Open%20Source.pdf>.
  This is the source for the Unix call model, the limits of `QSH CMD`, the
  `PATH` guidance, the Node.js geocode example, and the CL `.zip` listing
  example. Pages that use this material cite it as "Klement".
